# ClaudCode — торговля в MetaTrader 5 через Claude Code

```
Claude Code ──MCP/stdio──▶ bridge/server.py ──TCP 127.0.0.1:5555──▶ ClaudeGateway.mq5 ──▶ MT5
                            (инструменты, индикаторы, журнал)        (жёсткие риск-лимиты)
```

- **EA `ClaudeGateway`** — исполнитель и «охранник». Все лимиты проверяются внутри MT5, их нельзя
  обойти через API: макс. лот, макс. риск на сделку, дневной лимит убытка, число позиций и сделок
  в день, спред, торговое окно, кулдаун, обязательный SL, авто-закрытие в конце дня.
- **Python MCP-сервер** — даёт Claude инструменты, считает индикаторы (EMA, RSI, ATR, VWAP),
  пишет журнал всех действий с причинами в `bridge/logs/journal.jsonl`.
- **Kill switch** — кнопки на графике. Claude может только *остановить* торговлю
  (`pause_trading`), включить обратно — только человек.

> ⚠️ Начинайте на **демо-счёте**. Автоматическая торговля может привести к потере денег; LLM не
> гарантирует прибыль. Никогда не передавайте Claude пароль от торгового счёта — он не нужен.

## Установка (Windows, MT5 и Claude Code на одном компьютере)

### 1. Советник

1. В MT5: **Файл → Открыть каталог данных**, скопируйте `mql5/Experts/ClaudeGateway.mq5`
   в `MQL5/Experts/`.
2. Откройте его в MetaEditor и скомпилируйте (**F7**). Ошибок быть не должно.
3. **Сервис → Настройки → Советники**:
   - ✅ «Разрешить алгоритмическую торговлю»;
   - ✅ «Разрешить WebRequest для следующих URL» и добавьте `127.0.0.1`
     (это же разрешение нужно для сокетов; без него в журнале будет ошибка 4014).
4. Перетащите советник на любой график (например EURUSD M1). На вкладке «Общие» включите
   «Разрешить алгоритмическую торговлю», на вкладке «Входные параметры» настройте лимиты (см. ниже).
5. Включите кнопку **Algo Trading** на панели. В левом верхнем углу графика появится статус
   `Bridge: waiting for bridge...` и две кнопки.

### 2. Python-мост

```powershell
# Python 3.10+ (https://python.org, отметьте "Add to PATH")
cd путь\к\ClaudCode
pip install -r bridge/requirements.txt
```

Если команда `python` у вас называется `py`, поправьте `"command"` в `.mcp.json`.

### 3. Claude Code

Запустите `claude` в папке репозитория и одобрите MCP-сервер `mt5` из `.mcp.json`
(проверить: `/mcp`). Через несколько секунд EA подключится — статус на графике станет `CONNECTED`.

Попробуйте: «Покажи статус счёта и снимок рынка по EURUSD».

Чтение данных разрешено без подтверждений (`.claude/settings.json`); каждое торговое действие
Claude Code по умолчанию спросит у вас. Это и есть режим «с подтверждением». Для автономного режима
добавьте торговые инструменты (`mcp__mt5__place_order` и т. д.) в `permissions.allow`.

### 4. Интрадей-цикл

- Один цикл: `/intraday-check`
- Повторять каждые 15 минут, пока открыта сессия: `/loop 15m /intraday-check`

Правила, по которым Claude торгует, и базовая стратегия — в `CLAUDE.md`. Замените раздел
«Стратегия» на свою.

## Параметры советника

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `InpPort` | 5555 | Порт моста (совпадает с `MT5_BRIDGE_PORT` в `.mcp.json`) |
| `InpMagic` | 20261007 | Magic API-сделок. Claude управляет только ими |
| `InpAllowedSymbols` | EURUSD,GBPUSD,USDJPY,XAUUSD | Символы для торговли (`*` — любые). Учтите суффиксы брокера (`EURUSD.m`) |
| `InpReadOnly` | false | Только чтение, любые торговые команды отклоняются |
| `InpMaxLot` | 0.10 | Макс. объём ордера |
| `InpMaxRiskPct` | 1.0 | Макс. риск на сделку, % эквити (по расстоянию до SL) |
| `InpMaxDailyLossPct` | 3.0 | Дневной лимит убытка от эквити на начало дня. Срабатывает до конца дня |
| `InpCloseOnDailyLoss` | true | При достижении лимита закрыть API-позиции |
| `InpMaxOpenPositions` | 3 | Макс. API-позиций + отложенных ордеров |
| `InpMaxTradesPerDay` | 10 | Макс. новых входов в день |
| `InpMinSecondsBetween` | 60 | Пауза между входами |
| `InpMaxSpreadPoints` | 30 | Макс. спред для входа, пункты |
| `InpRequireSL` | true | SL обязателен и не может быть снят |
| `InpOnlyTightenSL` | true | SL можно двигать только в сторону прибыли |
| `InpStartHour`/`InpEndHour` | 8 / 21 | Окно новых входов (время сервера) |
| `InpFlattenHour`/`InpFlattenMinute` | 22:45 | Автозакрытие API-позиций (−1 — выкл.) |

Лимиты работают в EA постоянно, даже когда Claude Code закрыт.

Кнопки на графике:
- **API TRADING: ON/OFF** — kill switch новых входов (состояние сохраняется между перезапусками);
- **CLOSE ALL API + STOP** — закрыть все API-позиции и ордера и выключить торговлю.

## Инструменты MCP

| Инструмент | Что делает |
|---|---|
| `get_status` | Подключение, счёт, состояние риск-лимитов |
| `get_market_snapshot` | Котировка + индикаторы по M5/M15/H1 |
| `get_symbol_info`, `get_rates` | Спецификация символа, сырые бары |
| `get_positions`, `get_orders`, `get_history` | Позиции, ордера, сделки и реализованный P/L |
| `get_journal` | Последние действия Claude с причинами |
| `place_order` | Рыночный/лимитный/стоп ордер, объём через `risk_pct` или `volume`, SL обязателен |
| `modify_position`, `close_position`, `cancel_order`, `close_all` | Управление API-позициями |
| `pause_trading` | Выключить kill switch |

## Протокол

Запрос (мост → EA) — строка `key=value`, разделённых TAB: `id=7⇥cmd=place_order⇥symbol=EURUSD⇥side=buy⇥sl=1.0812⇥risk_pct=0.5`.
Ответ (EA → мост) — строка JSON: `{"id":7,"ok":true,"result":{...}}` или `{"id":7,"ok":false,"error":"..."}`.
EA — TCP-клиент (MQL5 не умеет принимать входящие соединения без DLL) и переподключается каждые 3 с.

## Разработка и тесты

```bash
pip install -r bridge/requirements-dev.txt
python -m pytest bridge/tests
```

`bridge/tests/fake_ea.py` эмулирует советник, поэтому мост и MCP-инструменты можно проверить без MT5:
`python bridge/tests/fake_ea.py --port 5555`.

## Ограничения

- Время в данных — время сервера брокера.
- Дневной лимит считается от эквити в момент первого запуска EA за день; пополнения и выводы в течение
  дня искажают расчёт.
- Риск считается без комиссии; при большой комиссии оставляйте запас в `InpMaxRiskPct`.
- MCP-сервер работает, пока открыт Claude Code; одновременно может работать только одна сессия
  (порт занят).
