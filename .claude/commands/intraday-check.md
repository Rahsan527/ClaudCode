Выполни один цикл по правилам из CLAUDE.md:

1. `get_status`. Если EA не подключён, kill switch выключен, дневной лимит достигнут или мы вне торгового окна — кратко сообщи и закончи цикл без новых входов (управление открытыми позициями разрешено).
2. `get_journal` (последние 10) и `get_positions` — вспомни прошлые решения.
3. Для каждой открытой API-позиции: оцени по `get_market_snapshot`, нужно ли перенести SL в безубыток/подтянуть, частично зафиксировать или закрыть. Действуй только при явной причине.
4. Для символов из `allowed_symbols`: `get_market_snapshot`. Ищи сетап только из раздела «Стратегия» CLAUDE.md. Нет чёткого сетапа — не торгуй.
5. Если сетап есть и лимиты позволяют — `place_order` с `risk_pct`, обязательным SL и подробным `reason`.
6. В конце — сводка из 3–6 строк: состояние счёта, что сделано и почему, что ждём.
