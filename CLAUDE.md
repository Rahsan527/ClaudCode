# ClaudCode

## Субагенты

Субагентов запускай с `model: "haiku"` и `effort: "max"`, если пользователь не попросил другое.

## Справка по играм

- Справку для игроков пишет субагент `game-docs-writer`. Сам её не пиши — делегируй.
- Одна игра — один запуск агента. Несколько игр запускай параллельно.
- В задаче агенту укажи папку игры и путь для справки: `docs/help/<папка-игры>.md`.
- Когда агенты закончат, перешли пользователю пункты из их списков «Не удалось подтвердить».
